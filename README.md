# Pulse

轻量级校园网自动认证工具。用 Rust 编写，自动完成校园网 Portal 认证与保活。

## 为什么不用浏览器？

很多校园网需要开着浏览器网页才能保持网络连接，但浏览器方式有三个严重问题：

| 问题 | 说明 |
|------|------|
| 🐌 **资源占用大** | 浏览器动辄占用几百 MB 内存，只为发个心跳包，大炮打蚊子 |
| 😴 **页面休眠断网** | 浏览器或系统为了省电，会自动休眠网页标签页，导致心跳停止、网络断开，不得不频繁重新登录 |
| 🔒 **远程必杀** | 如果你用 UU 远程、Parsec、ToDesk 等软件远程连接学校电脑，浏览器一旦休眠断网，远程直接断开，而你已经连不上那台电脑了——**死循环**，只能让别人去学校帮你开机重连 |

**Pulse 就是来解决这些问题的**——一个不到 7MB 的小程序安安静静在后台跑，帮你一直保持网络在线。

## 特性

- **极低资源占用** — 内存占用忽略不计，无浏览器依赖
- **永不休眠** — 不会像浏览器标签页一样被自动休眠
- **自动检测本机 IP**，一键完成认证
- **密码输入不显示在屏幕上**，保护隐私
- **全中文交互界面**，非技术用户也能轻松上手
- **定时心跳保活**（每 5 秒一次），网络永不断线
- **支持 Windows / Linux**

## 使用

### 方法一：交互式配置（推荐）

直接运行程序，按提示输入信息即可：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Pulse - 校园网自动认证工具
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📝 未找到配置文件，开始设置...

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  校园网认证配置向导
  如果某一步不清楚，直接回车使用默认值
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

请输入学号：
请输入密码：
AC IP 地址 [10.240.192.33]：
...
```

配置会自动保存到程序所在目录的 `config.toml`。

### 方法二：手动创建配置文件

在程序所在目录创建 `config.toml`：

```toml
[credentials]
user_id = "你的学号"
password = "你的密码"

[network]
wlanacip = "10.240.192.33"
wlanacname = "gxmzu"
mac = "00:00:00:00:00:00"
vlan = "0"
base_url = "https://aaa.gxmzu.edu.cn"
```

然后双击运行程序即可。

## 自行构建

### Linux

```bash
cargo build --release
```

### Windows（交叉编译）

```bash
rustup target add x86_64-pc-windows-gnu
sudo apt install mingw-w64        # Debian/Ubuntu
cargo build --release --target x86_64-pc-windows-gnu
```
